# SKYNET — hovedegenskaper

- JARVIS-inspirert responsivt webgrensesnitt.
- Eget chatrom med flere samtaler og lokal samtalehistorikk.
- Stemme inn via nettleserens talegjenkjenning der dette støttes.
- Taleopplesing via nettleserens talesyntese.
- Valgfri Gemini API-integrasjon. Google tilbyr en gratis kvote med grenser som kan endres; brukeren oppretter og lagrer egen nøkkel lokalt i nettleseren.
- Lokal modus uten API-nøkkel, med enkel hjelpetekst og søkelenker.
- Direkte APK-nedlasting fra GitHub Releases.
- Mobilvennlig mørkt grensesnitt.
- Ingen SKYNET-server mottar API-nøkkelen eller chatthistorikken i denne statiske versjonen.
